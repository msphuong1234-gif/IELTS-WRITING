THEORY

Dynamic Charts – Công thức mô tả xu hướng

3.1. Công thức 5 thành phần

S – TREND – DEGREE – NUMBER – TIME

S = Subject • TREND = Verb/Noun chỉ xu hướng • DEGREE = Adverb/Adjective chỉ mức độ • NUMBER = số liệu • TIME = thời gian.

3.2. Sáu cấu trúc câu

  1. S + V + Adv + Number + Time
  2. There + be + a/an + Adj + Noun + in S + Number + Time
  3. S + experience/witness + a/an + Adj + Noun + Number + Time
  4. A + show + a/an + Adj + Noun + in the number/amount... + Number + Time
  5. Time + experience/witness + a/an + Adj + Noun + in S + Number
  6. Place + experience/witness + a/an + Adj + Noun + in S + Number + Time

3.3. Chọn chủ ngữ chính xác

Loại số liệuCụm nên dùng
Danh từ đếm được số nhiềuthe number / quantity / figure of + plural noun
Danh từ không đếm đượcthe amount / quantity / figure of + uncountable noun
Đơn vị %the percentage / proportion / rate / figure of ...

Reference word “figure”: cùng đối tượng → the figure / this figure; chuyển đối tượng → the figure for + đối tượng. Các chủ ngữ như the price of, the sales of, the income of không cần thêm quantifier.

NHỚ NHANH: TO – BY – OF – AT
TO = điểm đến • BY = mức thay đổi với động từ • OF = mức thay đổi với danh từ • AT = mức chính xác.

Time: in + month/year/century; on + day; at + hour; from...to...; between...and...; over/in/during + time.
